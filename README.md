# Java Internship Task - Palindrome Checker

A console-based Java application that checks whether a given string or number is a palindrome.

## Features

- **String Palindrome Checker**: Reverses a string and checks if it matches the original string (case-insensitive).
- **Number Palindrome Checker**: Reverses an integer using mathematical operations (`%` and `/`) and checks if it matches the original number.
- Interactive menu system using `java.util.Scanner`.

## How to Run

### Prerequisites
- JDK 8 or higher installed on your machine.

### Execution Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/sivasekhar-939/java-internship06.git
   cd java-internship06
   ```

2. Compile the Java code:
   ```bash
   javac PalindromeChecker.java
   ```

3. Run the program:
   ```bash
   java PalindromeChecker
   ```
